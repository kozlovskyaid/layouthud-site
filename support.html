Frequently Asked Questions

Why does the app need the Accessibility permission?

LayoutHUD uses the macOS Accessibility permission to detect which text field currently has keyboard focus and where it is on screen, so the layout indicator can appear right next to it. The permission is used only for this purpose. You can grant or revoke it in System Settings → Privacy & Security → Accessibility.

The badge doesn't appear — what should I check?

First, make sure LayoutHUD is enabled in System Settings → Privacy & Security → Accessibility. Then click into any text field — the badge shows up only while a text field is focused. If it still doesn't appear in a specific app, let us know which one.

How do I pin the badge to one spot on the screen?

Open Settings from the LayoutHUD menu bar icon, set Position to “Fixed”, uncheck “Pin position”, click into any text field and drag the badge with the mouse. Then check “Pin position” again.

How do I give each layout its own color?

In Settings, enable “Custom background color for each layout” and pick a color for every keyboard layout you use. This makes the current layout recognizable with peripheral vision, before reading a letter.

How do I make LayoutHUD start automatically?

Move the app to the Applications folder and enable “Launch at login” in Settings → General.

How do I quit or uninstall the app?

Click the LayoutHUD icon in the menu bar and choose “Quit LayoutHUD”. To uninstall, quit the app and move it from Applications to the Trash — this removes the app; settings are tiny preference entries you can leave or clean up with any preference cleaner.

Which languages does the interface support?

English, Russian, Spanish and Simplified Chinese. The app follows your macOS language; you can override it per-app in System Settings → General → Language & Region.
